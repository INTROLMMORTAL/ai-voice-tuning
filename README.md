# AI Voice Tuning

Расширение для Chrome (Manifest V3), которое **локально** анализирует ваш голос и автоматически подбирает обработку исходящего микрофона для голосового чата [nekto.me](https://nekto.me/audiochat). Работает как персональный звукорежиссёр: измеряет голос и комнату, подбирает цепочку эффектов, даёт A/B-сравнение с выравниванием громкости и сохраняет профиль.

> **Статус: рабочий прототип v0.2.** Ядро (DSP, анализ, автонастройка) покрыто тестами на синтетических сигналах. Версия 0.2 протестирована автором на живом nekto.me: обработка работает, блокировок доступа нет. Подробнее об ограничениях: [Ограничения](#ограничения).
>
> Проект неофициальный и никак не связан с nekto.me.

## Приватность

- Аудио не отправляется никуда. Нет серверов, аналитики и телеметрии.
- Запись микрофона идёт только при калибровке: после вашей галочки согласия и нажатия кнопки. Запись хранится в памяти вкладки Audio Lab и не пишется на диск.
- Сохраняются только параметры профиля и числовые метрики (`chrome.storage.local`).
- Не определяются личность, эмоции, возраст и другие чувствительные характеристики. Оценка основного тона нужна только для расчёта фильтра низких частот.
- Разрешения: `storage` и доступ к `https://nekto.me/*`.

## Как это работает

```
Микрофон → HPF → hum-notch → EQ (5 полос) → expander → de-esser → компрессор → limiter → в WebRTC сайта
```

1. **Калибровка** (~25 с): тишина, тихая, обычная и громкая речь.
2. **Анализ**: уровни (RMS, пик, громкость по BS.1770), шумовой пол и SNR, динамика, гул 50/60 Гц, клиппинг, обрывы сигнала, спектральный баланс, сибилянты.
3. **Автонастройка**: каждый параметр рассчитывается из ваших измерений и сопровождается объяснением. Коррекции ограничены и ослаблены: при сомнении выбирается консервативный вариант.
4. **A/B-прослушивание**: оригинал против вариантов Natural / Clear / Warm / Crisp, громкость выравнивается, есть «слепой» режим.
5. **Профиль** сохраняется локально, хранится 5 предыдущих версий с откатом.

### Режимы

| Режим | Что меняет в цепочке |
|---|---|
| Natural Voice | Минимум: HPF, лёгкая коррекция, limiter |
| Clear Voice | Присутствие 2–4 кГц, умеренная компрессия |
| Warm Voice | Немного тепла в низах, мягче верха |
| Crisp Voice | Чёткость, усиленный де-эссер |
| Noise Control | Сильнее expander и HPF, мягче компрессия |
| Broadcast | Сильнее компрессия, цель −18 LUFS |
| Low Latency | Только HPF, усиление и limiter |
| Custom AI Profile | Выбранный при калибровке режим плюс ручные правки |

### Audio Lab

Спектр входа и выхода, waveform, АЧХ эквалайзера, индикаторы уровня, сжатия, клиппинга и обрывов, ручные ползунки с журналом изменений, Reset, отмена и возврат к предыдущему профилю.

## Установка

1. Скачайте репозиторий (Code → Download ZIP) и распакуйте.
2. `chrome://extensions` → включите «Режим разработчика» → «Загрузить распакованное расширение» → выберите папку проекта. Нужен Chrome 111 или новее.
3. Нажмите иконку расширения → «Открыть Audio Lab» → «Включить микрофон» → поставьте галочку согласия → «Начать калибровку».
4. В разделе A/B выберите лучший вариант → «Сохранить профиль».
5. Откройте nekto.me/audiochat. После смены профиля или настроек перезагрузите вкладку.

## Предупреждение об использовании

Расширение подменяет аудиотрек микрофона внутри страницы сайта. Сайты могут реагировать на такое вмешательство: у автора после установки ранней версии появилась блокировка доступа (причина не установлена, снялась после очистки данных сайта). После перехода на версию 0.2, которая подменяет только `getUserMedia` и не оставляет на странице атрибутов и постоянных сообщений, автор тестировал расширение на живом nekto.me: всё работает, блокировок нет. Это результат одного тестировщика, а поведение сайта может измениться, поэтому используйте на свой риск. Расширение не скрывается от сайта и не обходит его защиту.

Проверенный безопасный путь: калибровка и настройка в Audio Lab (сайт при этом не затрагивается), включение на nekto.me осторожно, по одному разговору.

## Тесты

Нужен Node.js 20 или новее.

```
npm test
```

27 тестов: DSP-ядро (задержка, limiter, кривая компрессора, expander, де-эссер, плавность параметров, отклик EQ, устойчивость 60 с), анализатор (FFT, громкость по BS.1770, гул, клиппинг, обрывы, сибилянты), автонастройка (разные измерения дают разные параметры, все 8 режимов отличаются), диагностика и логика хука на заглушках браузерных API.

Для справки: полная цепочка в Node работает примерно в 60 раз быстрее реального времени.

## Ограничения

- **Тесты на синтетических сигналах**, не на реальных голосах и микрофонах. Целевая форма спектра в автонастройке приблизительная, поэтому коррекции ослаблены и окончательное решение за вашим слухом.
- **Хук проверен автором на живом nekto.me** (работает, без блокировок), а автотестами только на заглушках браузерных API. Сквозные замеры качества и задержки пока не проводились. Он может не сработать, если сайт получает микрофон нестандартным путём (iframe, worker, заранее полученный поток) или блокирует blob-worklet политикой CSP. В последнем случае включается упрощённая цепочка без gate, de-esser и компрессора.
- **Спектрального шумоподавления (RNNoise и т.п.) пока нет**, работает только expander. Модель будет добавлена, если измерения покажут пользу.
- **Сквозная задержка не измерена.** Алгоритмическая: lookahead limiter 1 мс плюс блок AudioWorklet около 2.7 мс. Режим Low Latency почти не меняет задержку (около 0.7 мс), его выигрыш в нагрузке на CPU.
- CPU внутри страницы надёжно не измерить: смотрите Диспетчер задач Chrome (Shift+Esc).
- Packet loss, джиттер и RTT обработка звука не исправляет. Модуль диагностики может только показать, что причина в сети.
- Custom AI Profile пока не обучается на истории ваших предпочтений.
- Эхоподавление остаётся на стороне браузера и сайта; расширение его не заменяет.

## Планы

- Опциональная диагностика WebRTC отдельным модулем.
- Спектральное шумоподавление, если подтвердится польза.
- Виртуальный аудиокабель для Windows как запасной вариант интеграции.
- Рекомендация пересчитать профиль при смене микрофона или заметном дрейфе уровня и шума.
